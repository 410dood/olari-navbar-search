# Release notes

## 1.0.0 (2026-09-03)

- Initial release.
- Any list data source; server-side `contains` filter over N string attributes, AND across typed words.
- Widgets slot for row content; On row click action receives the row object.
- Distinct "no results" and "no access" placeholders (1-row probe on first focus).
- No load on mount, debounce, page-size limit with Show more.
- Keyboard navigation, Escape and outside-click dismiss, ARIA combobox/listbox roles.
